# Plant Leaf Disease Detection using Deep Learning

This project focuses on identifying various plant leaf diseases early using image processing and machine learning/deep learning techniques. Early detection helps farmers take timely actions to protect crops and maximize yield.

## Features
* Automated detection of multiple plant leaf diseases.
* High accuracy using Convolutional Neural Networks (CNN).
* Developed using Python and Google Colab.
